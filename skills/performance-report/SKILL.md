Use performance_report for social observations and seo_report/read_workspace for web SEO baselines. Establish the time window, platform and data source before comparing metrics. Report observed performance, query metrics, content associations, comparable posts, missing-data coverage and actionable hypotheses in separate passages.

Use previous-period comparisons only with clear date windows and comparable coverage. Do not total overlapping topic buckets as independent traffic. Label example/demonstration data prominently. Distinguish public lifetime video counts from daily observations. State limitations before drawing conclusions about superiority or opportunity. Return a concise reviewable report; do not send it to anyone unless explicitly instructed.
