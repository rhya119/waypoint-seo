# Click-through introduction

Waypoint has an interactive introduction, not just a help article. On your first visit click **Start guided tour** in the welcome banner, or click **Take a tour** in the top bar at any time.

The normal app starts at **Domain overview**. Enter a public website and click **Analyze website** for an immediate robots-aware scan of the homepage and up to two eligible internal pages. Choose **Use saved / imported data** to open saved results without scanning. Use **Import SEO data → Validate preview → Import validated data** for CSV observations. Scanned topics/outbound links do not supply global keyword rankings or inbound backlink coverage. There is no fictional web demo option or preset example domain; empty sections explain which data to supply. See [the free SEO workflow](FREE_SEO.md) for export formats and button-by-button import steps.

The tour places a spotlight around the actual control and a short explanation beside it. For navigation/tab steps, **click the highlighted button** to advance. **Back** and **Next** also let you move at your own pace. **Skip tour**, the close button, or **Escape** ends it. Completing/dismissing saves a browser-local preference; replay is always available. Desktop and phone layouts are supported, with reduced-motion preferences respected.

It walks through:

1. Opening Social SEO and explicitly choosing fictional example data.
2. Filtering a topic and opening Keyword performance.
3. Opening Similar content, choosing a reference, and comparing accounts.
4. Finding the performance Export button.
5. Opening Integrations and the account setup/pull controls.
6. Returning to Social SEO → API snapshots for lifetime metrics.
7. Finding Import performance for daily content/query exports.
8. Finding Site audit for the limited public scan and optional pasted/uploaded HTML checks.
9. Finding source-aware domain Reports, with actual scans, supplied observations and optional provider data kept distinct.
10. Finding the optional whole-platform Claude plugin and host-computer subscription launcher.

The tour does not import data, run provider pulls, enable Claude, transmit analysis or download reports automatically. Example selection is explicit. Navigation may reset unsaved drafts; switch back to **My data** after the social example. For your Claude subscription, open **Start-Claude-SEO.cmd** on the host computer; the web advisor is a separate opt-in API feature. See [connection setup](CONNECTIONS.md), [daily data format](PERFORMANCE_DATA.md), [Claude installation](PLUGIN.md) and [private access](PRIVATE_SERVICE.md).

For performance data, choose dates and **Pull Google data** after configuring your own authorized Google access. **Fetch traffic estimates** is a separate explicit paid-provider action for complete calendar months. Both stay unavailable until their server credentials are configured; no private data is guessed. The tour itself never triggers these actions. Setup and source limits are in [FREE_SEO.md](FREE_SEO.md).
